# Workshop 2 materials: how these modules are built

## The thesis

16S counts and RNA-seq counts are the same kind of object. Every method in the
week is taught on one table and exercised on the other, with the same code.

| module | teach on | exercise on |
|---|---|---|
| 2, count table anatomy | both at once | both at once |
| 3, distances and ordination | species | genes |
| 4, differential testing | genes | species |
| 5, sets and enrichment | genes | species |
| 6, integration | lecture only | no exercise |

## Slides never compute anything expensive

Each coding module has a `_build_results.R` that runs the real analysis once and
writes small csv files into `results/`. The slides read those with `readr` and
plot them with `ggplot2`.

This matters for two reasons:

1. **CI stays light.** `renv.lock` has no Bioconductor in it, and the GitHub
   Action that deploys the site installs from `renv.lock`. Slides that called
   DESeq2 or microViz at render time would break the deploy.
2. **There is no cache to invalidate.** Every module's slides set
   `freeze: false`, so they re-render from the csv files every time. Change a
   number in `results/`, re-render, and the new number is on the slide. You never
   have to clear `_freeze/` by hand.

The heavy packages are only needed in the participant Codespace and on the
machine where you run the build scripts.

## Running a build script

The website's `.Rprofile` activates renv, which does not have the Bioconductor
packages. Turn the autoloader off for these scripts:

```bash
cd website
RENV_CONFIG_AUTOLOADER_ENABLED=FALSE \
  Rscript materials/2-workshop2/2-count-table-anatomy/_build_results.R
```

Run them in this order, because later ones read earlier results. Module 4's
script writes the sample grouping, so it runs before Module 3's even though
Module 3 is taught first:

```
2-count-table-anatomy   independent
4-differential          independent, writes sample_groups.csv
3-ordination            reads 4's sample_groups.csv
5-enrichment            reads 4's ranked results
6-integration           reads 4's sample_groups.csv
```

You need: `tidyverse`, `vegan`, `DESeq2`, `phyloseq`, `microViz`, `fgsea`,
`msigdbr`, `pROC`. microViz is not on CRAN; install it from r-universe after the
Bioconductor dependencies.

## The count table wrapper

`R/count_tables.R` is the one piece of workshop-specific code. It does two
things:

- `read_counts()` returns plain matrices and tibbles
- `as_counts(table = "microbiome" | "rnaseq")` returns a phyloseq object

The second one is why microViz works on genes. microViz wants a feature
annotation with ranks running coarse to fine; a gene annotation is that, so
`locus_group` and `symbol` are handed over as the two ranks. Every microViz verb
then works on the gene table unchanged.

This file must also exist at `R/count_tables.R` in the participant-env
repository, because that is the path the exercises tell participants to source.
It is kept in sync by copying; the website copy is the source of truth.

Note the data path differs between the two repositories, and the helper knows
both. The website serves `datasets/2-workshop2/`, the Codespace has
`data/2-workshop2/`. It must not be a bare `data/`, because Workshop 1 ships a
`data/instructional_dataset/` holding completely different files.

## Checking the participant environment

The participant-env repository has `.devcontainer/smoke-test.R`, which runs the
whole week once inside the built container: load both tables through the helper,
build the grouping column, run DESeq2, run both microViz ordinations and a
PERMANOVA, run fgsea, compute an AUC, then do the same for both group datasets.

Run it after any change to the Dockerfile, the datasets or the helper:

```bash
Rscript .devcontainer/smoke-test.R
```

It is the fastest way to find out that Tuesday morning will work.

## Datasets

`datasets/2-workshop2/` holds all three, each with the same six files and the
same column names. They are generated by a separate private repository; the
generator and the ground truth never ship. The data are constructed: real
sequencing, invented study labels. Every module says so at least once.
